# Portfolio - Inti Vidal

This is my personal portfolio website as a Civil IT Engineer and Bachelor of Science in Computer Science from Universidad Técnica Federico Santa María.

Here I showcase my professional background, technical proficiencies, featured software engineering projects, downloadable resume, and direct contact channels.

This is a standard [Next.js](https://nextjs.org/) project configured for static export. Refer to the [Next.js Documentation](https://nextjs.org/docs) for framework details and deployment workflows.

## Tech Stack & Libraries

- **Framework**: Next.js 16 (App Router, Static HTML Export)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **UI Components & Theme**: DaisyUI v5 (Retro theme)
- **Typography**: Slabo 13px via `next/font`
- **Containerization & Web Server**: Docker (multi-stage Alpine Linux build), Nginx
- **Infrastructure & CI/CD**: Google Cloud Platform (Compute Engine VPS), Cloudflare CDN / DNS, GitHub Actions
